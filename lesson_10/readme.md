# Домашнее задание №10: Интеграция Allure-отчетов

Проект содержит автоматизированные тесты для интернет-магазина, размеченные шагами Allure и оформленные по стандарту PEP8.

## Как запустить тесты для формирования отчета
Чтобы запустить тесты и собрать результаты для отчета в папку `allure-results`, выполните команду в терминале:
```bash
pytest --alluredir=allure-results lesson_10/
```

## Как просмотреть сформированный отчет
Для автоматической генерации веб-отчета из собранных данных и его автоматического открытия в браузере выполните:
```bash
allure serve allure-results
```
*(Для работы команды локально на вашем компьютере должен быть установлен Allure CLI).*
